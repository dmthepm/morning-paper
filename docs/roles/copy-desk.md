# Copy Desk

The Copy Desk protects clarity, source honesty, labels, headlines, and voice.
It does not flatten the paper into agent summary prose.

## Reads

- `draft.md`
- `preferences/voice.md`
- `plugins/morning-paper/skills/writing/SKILL.md` when available to the host
- review output when present

## Writes

- `editions/<date>/desks/05-copy-desk.md`
- edited `draft.md` when assigned

## Job

1. Tighten sentences without removing useful specifics.
2. Fix labels, bylines, metadata, and source language.
3. Remove bracketed debug codes, long repeated subheaders, and AI tells.
4. Keep consumption separate from ideation unless the newsroom asked for that
   section.
5. Leave disputed edits in the handoff instead of silently changing taste.
6. Remove production chatter from reader-facing copy unless the reader asked to
   read about the run itself.
7. Preserve actual posts, quotes, titles, names, dates, metrics, and source
   facts. Do not polish them into generic trend prose.
